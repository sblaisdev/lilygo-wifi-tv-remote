Initial Firmware Installation

Install the TV Remote firmware on your LilyGO T-Dongle-S3 directly from your web browser. No command line, no Python, and no drivers required!

⚠️ Cannot Run Directly from Local File (file://)

Web browsers block loading files (CORS) when HTML pages are opened directly from your hard drive, causing the "Failed to download manifest" error.

💡 To test locally: Run python -m http.server 8000 --directory docs or double-click run_local_web_installer.bat, then open http://localhost:8000/install.html.
🌐 On GitHub Pages: Once pushed, this installer works automatically over HTTPS!
⚠️ Web Serial is not supported in this browser. Please open this page in Google Chrome or Microsoft Edge. 🔒 Web Serial requires a secure connection (HTTPS or localhost).
⚠️ Browser Notice: Your current browser does not support the Web Serial API. Please open this installer in Google Chrome, Microsoft Edge, or Brave on Windows, macOS, ChromeOS, or Linux.

💡 Tips & Troubleshooting

Used this LilyGO for another project?

No problem! Check the "Erase device" option when prompted by the installer. This cleanly wipes the old firmware, partition layout, and old settings, giving you a fresh start.

Device not detected or connection fails?

If previous firmware is causing issues: unplug the dongle, hold down the small side button, plug it back into the USB port, and release the button. This forces the device into hardware download mode.

What about future updates?

You only need this web installer once! All future firmware updates can be installed wirelessly (OTA) directly through the TV Remote settings page over your home Wi-Fi.
